Для корректной работы расширения и получения доступа к его функционалу требуется выполнить авторизацию в системе, указав ключ приложения, логин и пароль, полученные при регистрации на сайте https://www.dev.dellin.ru/.

Параметры подключения

Авторизация выполняется под пользователем с правами Администратора системы.

На форме настроек соединения заполняются:

  • Ключ приложения - выдается при регистрации на https://dev.dellin.ru/;
  • Логин - создается при регистрации на https://www.dellin.ru/;
  • Пароль - создается при регистрации на https://www.dellin.ru/;
  • Адрес сервера - api.dellin.ru;
  • Прокси сервер - по необходимости;
  • Таймаут соединения - рекомендуемое значение от 0 до 60.

Проверка успешности авторизации выполняется по кнопке "Проверить подключение".

Заполнение ВГХ (весогабаритных характеристик)

На форме настроек подключения размещен блок настроек заполнения грузового места по документам основаниям при создании Заказа на доставку вводом на основании:

  • "Не заполнять;"
  • "Весь документ;"
  • "Строка табличной части документа";
  • "Количество товара";

Группа реквизитов "Значения ВГХ по умолчанию" используется в случае, когда у Номенклатуры не заполнены ВГХ ни в карточке товара, ни в упаковке. Реквизиты заполняются на форме настроек подключения. Значения реквизитов "Длина", "Ширина", "Высота", "Вес" и "Объем" пользователь заполняет вручную. Отдельно для реквизита "Объем" используется расчет при изменении параметров ДШВ по формуле "Объем = Длина * Ширина * Высота".

Заказчик

На форме настроек расширения можно задать заказчика по умолчанию и его роль в перевозке. Указанный в настройках контрагент будет автоматически подтягиваться на форму оформления заказа.
Для выбора доступны только те контрагенты, к которым есть полный доступ в Личном кабинете на сайте https://www.dellin.ru

Логирование

В Расширении реализован функционал логирования отправленных запросов и полученных ответов. Для хранения запросов используется добавленный регистр сведений "Лог api запросов (Деловые Линии)". Регистр, в отличие от настроек подключения, доступен всем пользователям, а не только Администратором. Регистр содержит информацию о запросе:

  • Дата;
  • Название метода;
  • Метод;
  • Время выполнения запроса;
  • Текст Отправленного запроса;
  • Текст Полученного ответа;
  • Пользователь, отправивший запрос.

Чтобы регистр не переполнялся, для него задан параметр, определяющий период хранения информации. Параметр "Количество дней логирования запросов к api" задается в настройках авторизации. По умолчанию установлено значение «0», что означает логирование отключено.

Информация о запросе и его текст нужны, прежде всего, для анализа ошибок, и используются Технической поддержкой при оказании консультаций.

Уведомление о выходе новой версии

На форму настроек подключения добавлена кнопка "Проверить наличие новой версии". При нажатии на кнопку система выполняет проверку появления новой версии на сайте Деловых Линий. Если появилась новая версия, то пользователю выдается информация о её номере и содержании. Появляются кнопка установки, ссылка для ручного скачивания и признак отключения уведомления о выходе новых версий.

При нажатии на кнопку "Установить новую версию" будет выполнена фоновая загрузка и установка расширения, после чего потребуется перезапустить базу и, в случае выхода мажорной версии, завершить сеансы других пользователей.

Важно! Для скачивания и установки внешнего файла у пользователя должны быть:

  • доступ во внешнюю сеть;
  • права на скачивание файлов из внешней сети;
  • права на открытие внешнего файла на стороне 1С;
  • интернет-соединение.

Если скачивание и установка расширения занимают более 1 минуты, процесс будет прерван, чтобы Пользователь смог продолжить работу и вернуться к вопросу обновления позднее.

Важно! На время всего процесса обновления работа в базе блокируется.

После завершения процесса обновления система выдаст сообщения об изменениях между версиями расширения и отдельное сообщение "Расширение обновлено. Перезапустите 1С!". После этого рекомендуется перезапустить базу, проверить что обновление расширения выполнено успешно - номер установленной версии равен номеру предыдущей версии, после чего продолжить работу в базе.

Уведомление о выходе новой версии появляется при открытии Журнала заказов в случае, если флаг "Больше не напоминать о выходе этой версии" не взведен. Взвести его можно как на форме настроек, так и при появлении уведомления.

Пример использования:

Если флаг взведен для версии 4.4, то до появления версии 4.5 или 5.0 уведомление не будет появляться. Если флаг не будет взвезен, то уведомление будет появляться при каждом запуске расширения при открытии Журнала заказов.
