Общая информация

Карточка заказа служит для визуализации данных отправленных заказов и мультизаказов. Для открытия карточки следует выбрать заказ в Журнале двойным кликом.

Карточка доступна только для просмотра.

Печать документов

Для просмотра, печати и сохранения в файл печатных форм из Карточки заказа требуется выбрать запрашиваемую печатную форму после нажатия на кнопку "Печать". Состав печатных форм зависит от текущего состояния заказа. Если печатная форма недоступна, она скрывается из общего списка.

Самостоятельная маркировка

Для получения этикетки со штрихкодом для маркировки грузовых мест и сопроводительных документов используется функционал Самомаркировки, который вызывается по кнопке "Маркировка". Сначала следует отправить артикулы перевозимых грузомест, после чего можно будет получить сформированные на стороне ДЛ этикетки.

Изменение заказа после отправки

Система позволяет вносить изменения в уже отправленный Заказ на доставку. Для изменения заказа следует нажать на кнопку "Внести изменения", выбрать доступное изменение, внести новые данные и применить изменение. При изменении реквизитов учитываются ограничения, связанные со статусом отправленного заказа, а также заполненных значений, таких как тип доставки (адрес/терминал), даты отправки и получения, данные отправителя и получателя и др.

Возможность внесения изменений в заказ доступна до 17:00 (по местному времени) последнего рабочего дня, предшествующего дню забора / доставки груза.
