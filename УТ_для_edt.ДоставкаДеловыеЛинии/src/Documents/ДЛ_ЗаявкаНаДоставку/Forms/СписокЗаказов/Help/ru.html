Журнал заказов

На форме отображаются списки документов Заказы на доставку (Деловые Линии), которые:

  • Были отправлены в Деловые Линии;
  • Доступны для объединения в мультизаказ с последующей отправкой;
  • Доступны для объединения в Пакетный заказ;
  • Неотправленные черновики заказов.

Создание заказов на доставку

Для создания Заказа на доставку необходимо нажать на кнопку «Создать».

Создание Мультизаказа

Для создания мультизаказа необходимо нажать на кнопку «Создать мультизаказ» и в открывшемся окне вручную выбрать какие из заказов в статусе «Черновик» будут собраны в мультизаказ.

Отбор по отправленным заказам

Для поиска Заказа на доставку в списке отправленных рекомендуется использовать поиск во всплывающем окне, которое откроется при нажатии на гиперссылку «Настроить отбор». Доступен поиск по Номеру заказа, Дате создания и Статусу;

Работа с неотправленными заявками

Для продолжения работы с неотправленными заказами (Черновиками) необходимо пройти по гиперссылке «Неотправленные документы». В открывшемся список следует выбрать одну из заявок и приступить к её редактированию или удалить.

Печать документов

Для просмотра, печати и сохранения в файл печатных форм из Журнала заказов требуется открыть карточку выбранного заказа и в открывшемся окне по кнопке «Печать» выбрать запрашиваемую печатную форму. Состав печатных форм зависит от текущего состояния заказа. Если печатная форма недоступна, она скрывается из общего списка.

Самостоятельная маркировка

Для получения этикетки со штрихкодом для маркировки грузовых мест и сопроводительных документов используется функционал Самомаркировки, который вызывается по гиперссылке "Маркировка". Сначала следует отправить артикулы перевозимых грузомест, после чего можно будет получить сформированные на стороне ДЛ этикетки.

Изменение заказа после отправки

Система позволяет вносить изменения в уже отправленный Заказ на доставку. Для изменения заказа требуется открыть карточку заказа и по кнопке "Внести изменения" выбрать доступное изменение, внести новые данные и применить изменение. При изменении реквизитов учитываются ограничения, связанные со статусом отправленного заказа, а также заполненных значений, таких как тип доставки (адрес/терминал), даты отправки и получения, данные отправителя и получателя и др.

Возможность внесения изменений в заказ доступна до 17:00 (по местному времени) последнего рабочего дня, предшествующего дню забора / доставки груза.
