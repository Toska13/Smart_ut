Документ Заказ на доставку предназначен для оформления в системе заявки на грузоперевозку. При создании документа данные о заказе автоматически переносятся в личный кабинет на сайте Деловых линий. Возможность формирования в системе заказов на доставку определяется функциональной опцией Заказы на доставку (Деловые линии) в разделе Склад и доставка – Управление доставкой.

Предварительный расчет

Также в документе Заказ на доставку возможно сделать предварительный расчет стоимости заказа. Для этого необходимо заполнить следующий перечень обязательных полей и нажать кнопку «Рассчитать» в боковой панели справа:

  • На вкладке «Основные параметры»:
    • Блок общих параметров;
    • Блок параметров «Отправитель»;
    • Блок параметров «Получатель»;
    • Блок параметров «Способ отгрузки» (независимо от выбранной опции Забор от адреса/Самопривоз»);
    • Блок параметров «Способ доставки» (независимо от выбранной опции «Доставка до адреса/Самовывоз»);
  • На вкладке «Параметры груза»
    • Стоимость груза;
    • Характер груза;
    • Весогабаритные характеристики груза;
  • На вкладке «Плательщик»:
    • Блок параметров "Плательщик";
  • На вкладке «Услуги»:
    • Дополнительные услуги;

После заполнения обязательных полей в боковой панели запускается расчет всех доступных видов доставки. Подробный расчет выполняется только для одного вида, поэтому для подробного расчета по другому вида доставки, например, "Экспресс", потребуется запустить предварительный расчет по кнопке "Рассчитать" и дождаться завершения расчета. В случае изменения какого-либо обязательного поля возможность отправки заказа блокируется до успешного выполнения предварительного расчета с новыми данными.

Отправка заказа

Отправка заказа доступна при выполнении двух условий:

  • Доступность кнопки "Отправка заказа" после успешного Предварительного расчета;
  • Корректно заполненные поля на всех вкладках Заказа на доставку;

Вкладка «Основные параметры»

НА вкладке «Основные параметры» заполняются основные параметры заказа, в т.ч.:

  • Ваша роль в процессе доставки (определяется выбором в выпадающем списке);
  • Непосредственный Заказчик – контрагент из справочника Деловых Линий;
  • Признак Упрощенной отправки (без указания Контрагента);
  • Данные Отправителя:
    • Контрагент (выбор из справочника Контрагенты/Организации);
    • ИНН;
    • Контактное лицо;
    • Телефон (доступно указание до 3х номеров через «;»);
    • Организационно-правовая форма (только для иностранных юрлиц);
    • Участник перевозки иностранец (только для физлиц);
    • Страна регистрации (только для иностранных физлиц);
    • Номер иностранного паспорта (только для иностранных физлиц);
  • Данные Получателя:
    • Контрагент (выбор из справочника Контрагенты/Организации);
    • ИНН;
    • Контактное лицо;
    • Телефон (доступно указание до 3х номеров через «;»);
    • Организационно-правовая форма (только для иностранных юрлиц);
    • Участник перевозки иностранец (только для физлиц);
    • Страна регистрации (только для иностранных физлиц);
    • Номер иностранного паспорта (только для иностранных физлиц);
  • Способ отгрузки:
    • при выборе варианта отгрузки "Забор от адреса"
      • Населенный пункт (выбор из справочника населенных пунктов для использования подсказок по вводу адреса);
      • Откуда (заполнение адреса нахождения груза; указание наименование населенного пункта или координат);
      • Время отгрузки (указание временного интервала с обеденным перерывом);
      • Признак фиксированного времени забора с диапазоном в полчаса;
      • Дата отгрузки;
      • Внутренний номер заказа.
    • при выборе варианта отгрузки "Самопривоз" (самостоятельный подвоз груза к терминалу Деловых линий):
      • Населенный пункт(выбор из справочника населенных пунктов);
      • Город (выбор из справочника Города);
      • Терминал (выбор из справочника Терминалы);
      • Дата отгрузки;
  • Способ доставки:
    • при выборе варианта отгрузки "Доставка до адреса"
      • Куда (заполнение адреса нахождения груза; указание наименование населенного пункта или координат);
      • Время доставки (указание временного интервала с обеденным перерывом);
      • Признак фиксированного времени доставки с диапазоном в полчаса;
    • при выборе варианта доставки "Самовывоз" (самостоятельный забор груза из терминала Деловых линий):
      • Населенный пункт(выбор из справочника населенных пунктов);
      • Терминал (выбор из справочника Терминалы);

Вкладка «Параметры груза»

На вкладке «Параметры груза» заполняются основные параметры перевозимого груза, в т.ч.:

  • Стоимость груза в рублях;
  • Характер груза (определяется выбором в выпадающем списке из справочника Характер груза);
  • При выборе Одноместного груза:
    • Вес груза, кг;
    • Объем, м3;
    • Длина, мм/см/м;
    • Ширина, мм/см/м;
    • Высота, мм/см/м;
    • Если груз негабаритный (вес места от 800 кг или одно из измерений равно или более 3 метров), параметры негабаритных мест:
      • Вес, кг;
      • Объем, м3;
  • При выборе Нескольких грузовых мест:
    • Количество мест, шт.;
    • Общий вес, кг;
    • Общий объем, м3;
    • Максимальные весогабаритные характеристики:
      • Длина, мм/см/м (в поле указывается максимальное измерение среди всех негабаритных грузов, с учетом переворота);
      • Ширина, мм/см/м (в поле указывается 2-е максимальное измерение среди всех негабаритных грузов, с учетом переворота);
      • Высота, мм/см/м (в поле указывается 3-е максимальное измерение среди всех негабаритных грузов, с учетом переворота);
      • Вес, кг (в поле указывается максимальный вес одного негабаритного места);
    • Общие параметры всех негабаритных мест:
      • Вес, кг (в поле указывается общий вес всех негабаритных грузов);
      • Объем, м3 (в поле указывается сумма объемов каждого негабаритного груза);

Вкладка «Плательщик»

На вкладке «Плательщик» указываются:

  • Данные Плательщика:
    • Основной плательщик (за межтерминальную доставку);
    • Плательщик за забор от адреса
    • Форма оплаты (выбор в выпадающем списке);
  • Данные электронного чека: (с случае, если Плательщик - Физическое лицо)
    • Согласие на отправку электронного чека по почте;
    • Email;
    • Телефон;
  • Наложенный платеж (если Заказчик – Отправитель, Получатель – физ. Лицо, Основной Плательщик = Получатель, Форма оплаты - Наличные/Банковская карта, и у Клиента заключен специальный договор с Деловыми Линиями);
    • Вид оплаты (Наличные или Банковская карта);
    • Внутренний номер заказа;
    • Дата создания заказа;
    • Товарный состав (список Номенклатуры, количество и цена);

Вкладка «Услуги»

На вкладке «Услуги» указываются:

  • Действия с сопроводительными документами (выбор в выпадающем списке);
  • Параметры отгрузки:
    • Использование дополнительных требований к ТС (гидроборт, манипулятор, открытая машина, боковая/верхняя загрузка);
    • Необходимость погрузо-разгрузочных работ;
  • Параметры доставки:
    • Использование дополнительных требований к ТС (гидроборт, манипулятор, открытая машина, боковая/верхняя загрузка);
    • Необходимость погрузо-разгрузочных работ;
  • Требуемые упаковки:
    • Плательщик (оплата дополнительных услуг может производиться не основным плательщиком по заказу);
    • Выбор дополнительных упаковок);
  • Комментарий.

Мультизаказ - функционал, позволяющий объединить несколько заказов в один по признаку общего адреса Отправки. Формирование мультизаказа выполняется в два этапа:

  • Создание Заказа на доставку и его сохранение в статусе "Черновик" (не путать с неотправленным документом!). Выполняется по кнопке "Отправить для мультизаказа" после успешного «Предварительного расчета»;
  • Объединение нескольких черновиков мультизаказа для их отправки. Окно выбора "Создание мультизаказа" открывается из формы Журнала заказов по кнопке "Создание мультизаказа"
  • Далее происходит само объединение: Пользователь вручную определяет те заказы, которые он объединяет в мультизаказ
  • После выбора заказов для объединения и нажатия на кнопку "Разместить мультизаказ", заказ будет отправлен и доступен для просмотра в общем журнале.
  • Признаком мультизаказа является объединенный комментарий - в нём содержится информация о входящих в мультизаказ одиночных заказах. При просмотре содержимого заказа можно увидеть состав и контактную информацию по каждому из заказов

Шаблон заказа

Если требуется многократное заполнение одних и тех же параметров, рекомендуется использовать шаблон заказа. Шаблон может быть создан в любой момент работы с заказом по нажатию на кнопку «Сохранить шаблон». После нажатия на кнопку, потребуется дать шаблону имя и выбрать способ заполнения заказа при использовании шаблона. Их можно изменить после сохранения шаблона.

Для каждого шаблона определяется способ заполнения заказа. Это сделано для максимально гибкого настройки использования шаблонов.

Варианты заполнения заказа из шаблона:

  • Заполнять данными шаблона все поля в заказе;
  • Заполнять в заказе только те поля, которые заполнены в шаблоне;
  • Заполнять данными шаблона только пустые поля в заказе;

Шаблоны сохраняются в отдельном регистре сведений "Шаблоны (Деловые Линии)". Благодаря этому варианту сохранения, шаблоны становятся доступны всем пользователям, а не только автору шаблона. Открыть регистр сведений можно выбрав в выпадающем списке шаблонов "–- Открыть все шаблоны ---" и нажав на кнопку "Открыть":

В открывшемся списке шаблонов можно:

  • Выбрать шаблон для заполнения по двойному нажатию на него;
  • Изменить любой из имеющихся шаблонов по кнопке "Изменить";
  • Безвозвратно удалить его по кнопке "Удалить";

Таким образом, если при сохранении шаблона был выбран неверный способ заполнения, пользователь может открыть шаблон в общем списке и выбрать нужный ему способ. Например, "Заполнять только те поля, которые заполнены в шаблоне", чтобы дозаполнить заказ, созданный вводом на основании.

При выборе шаблона из общего списка список закроется, а в поле "Шаблон" заполнится название выбранного шаблона.

При выборе шаблона для заполнения у него заполняется поле "Дата использования". Эта дата используется для сортировки шаблонов в выпадающем списке - от наиболее свежего к наименее свежему.

Не путайте дату использования с датой создания.

Шаблоны заказов на доставку хранятся добавленном регистре расширения, и при удалении расширения будут утеряны навсегда.
