Справочник "Учетные записи MS Exchange"

Назначение

Справочник предназначен для хранения учетных записей пользователей MS Exchange.

Создается в подсистемах:

«Настройки»

Реквизиты:

Сервер MS Exchange

Сервер MS Exchange. (Серверы MS Exchange)

Пользователь

Пользователь учетной записи. (Пользователи)

Логин (включая домен)

Логин для подключения к серверу MS Exchange. (Строка)

Пароль

Пароль для подключения к серверу MS Exchange. (Строка)

Адрес e mail

Адрес электронной почты. (Строка)
