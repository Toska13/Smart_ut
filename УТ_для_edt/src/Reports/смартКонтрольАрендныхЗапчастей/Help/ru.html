Стоимостная оценка складов

Отчет предназначен для оценки стоимости товаров на складах предприятия по любому из выбранных видов цен, зарегистрированному в справочнике Виды цен.

Используемые формулы:

1. Оборачиваемость, дни = [Дней в периоде] / [Коэффициент оборачиваемости], где

[КоэффициентОборачиваемости] = [Продажи за период] : (([Нач. остаток] + [Кон. остаток]) / 2)

2. Висяки = [Кон. остаток] - [Количество для 45 дней], где


[Количество для 45 дней] рассчитываются исходя из формулы уровня запасов на складе:

[Уровень запасов] = [Кон. остаток] * ([Дней в периоде] / [Продажи за период])

Если в этой формуле вместо [Уровень запасов] подставить 45, а в качестве неизвестого взять [Кон. остаток], то можно получить количество товара, которое должно продаться за 45 дней:

[Количество для 45 дней] = 45 * ([Продажи за период] / [Дней в периоде])

3. Рентабельность = (Выручка - Себестоимость - Трудозатраты - Доп. расходы - Постатейные постоянные - Постатейные переменные) / Выручка * 100%
